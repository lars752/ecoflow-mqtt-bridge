# Dokumentation: EcoFlow MQTT Bridge

Dieses Add-on emuliert und vereint alle Funktionen des ioBroker-Adapters `ioBroker.ecoflow-mqtt` in einem autarken Node.js-Container für Home Assistant.

## Funktionen
- **EcoFlow Cloud Authentifizierung & API-Anbindung**
- **Vollständiges State-Flattening** für alle verschachtelten Gerätedatenpunkte
- **Home Assistant MQTT Discovery** (automatische Erkennung von Sensoren, Batterieständen, Watt-Werten, Temperaturen)
- **Konfigurierbare MQTT-Verbindung** (Standard: `core-mosquitto`)
- **Vollständiges GUI-Optionen-Mapping** via Home Assistant Interface
